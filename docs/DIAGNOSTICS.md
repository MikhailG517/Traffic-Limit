# Диагностика Traffic Limit

## Как включить

Диагностику можно включить любым из способов:

1. Пункт меню системного трея **«Диагностика»**.
2. Тумблер **«Диагностика»** в разделе «Настройки».
3. Запуск с ключом:

   ```text
   traffic_limit.exe --diagnostics
   ```

При включении приложение пишет в лог подробные события: запуск, работу трея,
включение/отключение ограничения, опрос скорости, получение счётчиков
процессов, ошибки и stack trace.

## Где находятся логи

Лог-файл создаётся в каталоге данных приложения:

```text
<ApplicationSupportDirectory>\traffic-limit.log
```

Типичный путь в Windows:

```text
%APPDATA%\TrafficLimit\traffic-limit.log
```

Точный путь можно открыть кнопкой **«Папка с логами»** в «Настройках» (или
пунктом трея **«Открыть журнал/логи»**). Кнопка **«Экспорт»** копирует текущий
лог в папку «Загрузки».

## Формат строки

```text
2026-08-15 09:35:33.123 [INFO ] Приложение запущено
    params: {startHidden: true, diagnostics: true}
```

Каждая запись содержит:

- временную метку с миллисекундами;
- уровень: `DEBUG`, `INFO`, `WARN`, `ERROR`;
- описание события;
- `params:` — значения ключевых параметров;
- `error:` и `stack:` — при исключении/ошибке.

Пароли, токены и секреты маскируются как `<filtered>` и в лог не пишутся.

## Что прислать для диагностики

Выполните сценарий, который не работает (например, включите лимит `30 Мбит/с`
или откройте вкладку «Приложения»), затем:

1. Откройте «Настройки» → «Папка с логами» (или Экспорт).
2. Пришлите файл `traffic-limit.log`.

Если среди симптомов есть «приложения показывают нет данных» — также пришлите:

- состояние строки статуса на вкладке «Приложения»
  («Активно» / «Служба не отвечает» / «Драйвер WinDivert недоступен»);
- результат запуска службы от имени администратора:

  ```text
  sc query TrafficLimitService
  sc query WinDivert
  ```
