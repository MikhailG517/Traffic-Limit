# План тестирования Windows 11

## Автоматические проверки

```powershell
flutter analyze
flutter test
```

## Ручной smoke-test на чистой VM

- установить одним `.exe`, проверить UAC и создание ярлыка;
- проверить `Get-Service TrafficLimitService` и запуск после перезагрузки;
- проверить реальное обновление счётчиков во время загрузки файла;
- задать лимит 1 Мбит/с и сравнить `iperf3` до/после;
- проверить контекстное меню трея, паузу и возврат окна;
- переключить автозапуск, перезагрузить VM, проверить сохранение параметров;
- просмотреть/экспортировать лог;
- удалить приложение, убедиться, что служба, ярлык и autorun удалены.

В текущем Linux-контейнере выполнены `flutter analyze` без ошибок компиляции и `flutter test` — все 3 теста прошли. Windows-specific build и VM smoke-test требуют Windows host.
