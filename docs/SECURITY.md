# Безопасность и права

Traffic Limit работает с сетевым kernel driver, поэтому требует повышенного внимания:

- установщик и service должны быть подписаны сертификатом издателя;
- WinDivert.sys должен быть официальной совместимой версией и иметь корректную подпись;
- установка и удаление службы выполняются только с UAC;
- named pipe должен быть ограничен локальными администраторами и SYSTEM в production hardening;
- не следует отключать Secure Boot, Driver Signature Enforcement или антивирус;
- перед релизом проверьте hash артефактов и протестируйте rollback/uninstall.

Сборка без WinDivert намеренно не ограничивает сеть. Это предотвращает ложное ощущение защиты и случайное изменение системных настроек.
